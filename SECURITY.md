# Security Policy

## Reporting a vulnerability

Please report security issues privately.

Use this repository's **Security → Report a vulnerability** form when private vulnerability reporting is enabled. See [GitHub's private reporting instructions](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately). Include the affected commit or release, reproduction, expected and actual behavior, impact, and any proposed fix. Never include private keys, credentials or private operator evidence.

If the private form is unavailable and you do not already have a verified maintainer contact, open a public issue **only to request a private reporting channel**. Include no vulnerability description, affected component, reproduction or exploit details in that public request. Do not publish technical details until coordinated disclosure.

## NFT trading

This contract does not include an internal NFT marketplace. AGI Jobs are standard ERC-721 NFTs and can be traded on external marketplaces using normal approvals and transfers.

We will acknowledge receipt and coordinate a fix and disclosure timeline when possible.
