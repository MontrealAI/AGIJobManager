# Standalone interfaces

- [Published v0.9.5 USDC console](https://github.com/MontrealAI/AGIJobManager/releases/download/v0.9.5/agijobmanager-usdc.html): use with a verified v0.9.5 manager and release checksums.
- [USDC development console](../../ui/agijobmanager-usdc.html): unreleased follow-up; voting requires a separately deployed manager with `getJobBonds`. See [compatibility and the earlier bond-quote limitation](../qualification/BUYER_ECONOMICS_FOLLOWUP.md).
- [Repository single-file app](../../agijobmanager.html): bundled overview with deployment-required defaults.
- [Operator interface](agijobmanager.html): configurable action interface with USDC transaction guards.

All current interfaces use six-decimal USDC. No USDC manager is deployed by this release. Previous consoles are preserved in the [v0.4.0 source](https://github.com/MontrealAI/AGIJobManager/tree/v0.4.0/ui).
