# Start here — AGIJobManager v1.9.0

1. Read `RELEASE_NOTES.md` and `VALIDATION.md` for changes and test scope.
2. Open `agijobmanager-usdc.html` for the manual USDC console. Configure only your verified deployment; the release does not record or activate a live manager.
3. Follow `source/docs/OPERATIONS/NO_RETAINERS.md` for current admission and upgrade rules. New work uses calibrated operator budgets. Keep old journals and policies for existing claims and refunds.
4. Read `source/docs/OPERATIONS/GENERAL_COMPUTER_WORK.md` and `source/docs/OPERATIONS/COMPUTER_USE_CURRENT.md` for computer-work specifications, actual runtime checks and present adapter coverage.
5. For deployment, begin with `source/hardhat/README.md` and `source/docs/RELEASE_GUIDE.md`, offline checks and an explicit read-only plan.
6. Verify the ZIP and standalone console against `SHA256SUMS.txt` and `RELEASE_MANIFEST.json`.

The private companion packages are Fleet 1.7.0, Agent 1.13.0 and Node 2.14.0, delivered separately with complete source and offline guides. Start with their `START_HERE.html`. Reuse the existing data directories, preserve earned rights and commission the exact Mac/provider setup before resuming new work.
