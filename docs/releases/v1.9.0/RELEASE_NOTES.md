# AGIJobManager v1.9.0 — Computer work without retainers

AGI Jobs covers work a person or team can perform with a keyboard, mouse and screen. This release improves admission and execution of general computer work and adopts operator budgets for new review work.

- **No new retainers.** The operating admission boundary and economic CLI require schema 6/7 `operator-budget` policies. Historical policy analysis, earned credits and refund recovery remain available. Existing contracts and settlement rewards are unchanged.
- **Feasible start times.** A reusable execution-window check requires the full declared work duration, queue time and completion reserve to fit before the applicable deadline. The private Node checks its actual chain review deadline before paid inference.
- **Actual runtime binding.** The private worker verifies the configured creator/reviewer model, sandbox tools and pinned desktop/browser images. Silent fallbacks, host-control substitutions and unimplemented dependency coordination cannot claim readiness.
- **Durable review spending.** The private Node requires a recorded job/policy budget reservation before voting; failed attempts and restarts preserve spent allowances. Employer funding with no review retainer no longer requires a review-funding policy.
- **Current computer-use guidance.** Provider and OpenClaw documentation informs the integration notes. The general specification accepts native outputs and task-specific acceptance evidence without a profession list. Actual capability must be demonstrated for each commissioned environment.
- **Aligned downloads and guides.** Public package identities, deployment registry and generated UI documentation now agree on v1.9.0.

Companion editions: **Fleet 1.7.0, AGI Agent 1.13.0 and AGI Node 2.14.0**, delivered privately. The fleet also includes Employer, Moderator, Evidence and Recovery services. New retainer approval, funding and activation are disabled; existing recovery remains available. Preserve operator state and use newly signed operator-budget policies when upgrading.

Validation includes 677 public contract/tool cases, all five source workflows, UI and security checks, and 34 historical USDC/ENS fork cases. The private companions passed 412 unit tests and local contract lifecycle rehearsals. Release publication verifies the exact source checkout and reproduces the download archive before publishing checked assets. See `VALIDATION.md` for evidence and limits.

All Solidity files, deployed payout rules and historical release/deployment records are preserved. No contracts are deployed and no intake is activated by this release. The bundled private worker currently executes isolated public computer work; signed-in native Mac applications and private-account adapters still require implementation and commissioning. Actual M1/M2 operation, provider invoices, independent validation quality and sustained useful throughput remain to be measured. No new profitability or universal autonomy claim is made.
