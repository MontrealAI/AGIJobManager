# Candidate validation

The package manifest identifies exact source and file hashes; it alone does not
qualify the software. Applicable final-source workflow jobs and steps must pass.
See the external `QUALIFICATION.json` for a published release and the source's
`QUALIFICATION_REPORT.md` for preparation status. Missing archive access, original
operator compiler cache, private approvals or participant evidence must not be
reported as synthetic PASS. Every downloadable asset is limited to 450,000,000 bytes.
