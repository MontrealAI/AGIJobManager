# Start here — AGIJobManager v1.12.0

1. Read RELEASE_NOTES.md and VALIDATION.md, then source/README.md for the current overview.
2. Open source/docs/OPERATIONS/VALUE_TIER_PILOT.md to choose useful work and freeze a bounded real-machine pilot.
3. From source, run `npm run workforce:economics -- examples/project-economics-100.json`. The $1,000 and $10,000 teaching examples deliberately reject uneconomic assumptions. Planning has no execution or spending authority.
4. Read source/docs/OPERATIONS/OPERATING_QUALIFICATION.md. Production V2 now enforces loss and supervision ceilings per held-out cohort. New source requires matching independently signed evidence.
5. Private companions: Fleet 1.10.0, Agent 1.16.0, Node 2.17.0. Open their offline START_HERE.html; preserve original data directories, journals, pending payments and cumulative spending. Keep native compute and signing in separate Standard Mac accounts.
6. No new retainers. Verify downloads with SHA256SUMS.txt and RELEASE_MANIFEST.json. Publishing this software does not deploy a manager or open production intake.

Actual Macs, live provider competence, independent valuable-job outcomes, paid economics and external security assurance remain uncommissioned here. The native workflow has whole-account UI authority; scoped credential brokering and automatic private-to-chain settlement remain unimplemented.
