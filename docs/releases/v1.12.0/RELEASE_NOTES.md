# AGIJobManager v1.12.0 — Project economics and cohort safeguards

High job prices and positive aggregate profit can conceal frequent participant losses. This release makes those losses visible and tightens qualification before expanding work.

- **Stricter cohort qualification:** the existing signed V2 loss and supervision ceilings now apply within every held-out job class. Reports expose Agent/Node net cash, losing engagements and human time per useful completion.
- **Project cash-flow planning:** explicit success and failure scenarios, exact micro-USDC arithmetic, participant-specific capital, expected-net, loss-probability and worst-loss limits. All stages reserve capital; anticipated receipts cannot fund another stage. No intermediate payment or retainer is invented.
- **Useful pilot workflow:** $100/$1,000/$10,000 teaching examples and a guide for independent deliverable tests, actual bills, human time, restart and authority rehearsals. Examples remain assumptions, not completed customer work.
- **Current documentation:** refreshed main README, release/download labels, command inventory, computer-use guidance and private companion editions. Standard documentation generation/checking now includes generated UI deployment metadata.
- **Private companions:** Fleet 1.10.0, Agent 1.16.0 and Node 2.17.0 carry the same economics tools and invalidate stale screen/window observations after failed refreshes or clock rollback. They are separate private downloads, not public release assets.

Download the COMPLETE ZIP and open START_HERE.md, or use the standalone USDC console against a separately verified deployment. SOURCE_CI.json and VALIDATION.md identify executed checks; RELEASE_MANIFEST.json and SHA256SUMS.txt provide integrity evidence.

New work continues to use operator budgets without retainers. Existing escrow credits, claims, cumulative costs and recovery remain preserved. Solidity, ABI, payout rules and dependency resolutions are unchanged. No contract deployment, production activation or automatic model/provider upgrade occurs.

This is a software release prepared for controlled commissioning. Actual Mac/provider operation, independent real-job performance, paid economics and external security review remain unverified here. Native workflows retain whole-account UI authority and do not automatically settle private jobs on-chain. Updated source requires fresh matching operational attestations.
