# AGIJobManager v1.8.0 — General computer work and explicit review economics

AGI Jobs represents lawful work that a person or team can perform through a computer interface. This release adds an executable general job specification and makes reviewer payment a deliberate economic choice.

- `computer-work/v2` describes goal, environment, permissions, inputs, native outputs, acceptance/evidence criteria, deadlines, budgets and settlement/recovery context. It has no profession or extension catalogue. Runtime hashes bind the exact configured model, tools, policy and image.
- New signed participant/funding policy schemas 6/7 select `retainer` or `operator-budget`. Retainer policies preserve funded review protection; operator-budget qualification forecasts no retainer and retains calibration, economic loss, capital and gas checks. Existing schema 4/5 behavior and earned credits are preserved.
- Capability reports require complete planned engagement records, disjoint calibration/evaluation groups and exact runtime/specification hashes. Failures, timeouts and abstentions remain in the denominator. Missing provider bills leave profitability unknown; reports authorize no production action.
- A matched study used 10,000 unique offers and five scenario runs, with 1,997,604 independently replayed events. Retainers reduced useful output in the calibration cohort; neither tested alternative passed all improvement limits. Baseline was retained. An additional unplanned evaluation diagnostic is disclosed and excluded from policy selection.
- Current guides, package identities and deployment command references are aligned. UI qualification now runs on main pushes as well as pull requests.

**All Solidity files and existing payout rules are unchanged.** The optional review escrow remains a separate deployment. This software publication does not deploy contracts, change existing agreements or activate intake.

Companion private editions are Fleet 1.6.0, Agent 1.12.0 and Node 2.13.0, delivered privately. They add v2 artifact handling, actual configured-runtime checks, deadline cancellation, independent checklist evidence and durable operator-budget review reservations. Their adapter remains isolated public work; dedicated signed-in accounts and native private Mac applications require separate implementation and commissioning. Existing journals and retainer claims must be preserved during upgrades.

Read `source/docs/OPERATIONS/GENERAL_COMPUTER_WORK.md`, `source/docs/qualification/V180_10000_REPORT.md` and `VALIDATION.md`. The full source contains scenario results and limitations; the separate compact private download includes reproducible study inputs and scripts.

This is a commissioning candidate, not universal production qualification, measured Mac throughput or guaranteed participant profitability. No recent-model performance gain was invented in the simulation. Production still requires independent review and measurements on actual machines, providers, employers and native-USDC operating/recovery paths.
