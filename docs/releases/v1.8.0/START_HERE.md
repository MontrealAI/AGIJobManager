# Start here — AGIJobManager v1.8.0

1. Read `RELEASE_NOTES.md` for changes and `VALIDATION.md` for exactly what was tested.
2. Open `agijobmanager-usdc.html` for the manual USDC console. Publishing this file does not select a live manager or activate intake.
3. Use `source/docs/OPERATIONS/GENERAL_COMPUTER_WORK.md` for general job specifications, runtime qualification and review-payment choices. Use `source/docs/qualification/V180_10000_REPORT.md` for the matched experiment.
4. For a new deployment, follow `source/hardhat/README.md` and `source/docs/RELEASE_GUIDE.md`. Start with offline checks and an explicit read-only plan. Do not treat software publication as deployment approval.
5. Verify the download against `SHA256SUMS.txt` and the per-file `RELEASE_MANIFEST.json`. Release source is pinned in `release.json`; deployment and historical records retain their identities.

Private Agent, Node and Fleet packages are delivered separately. Preserve operator journals, wallet boundaries and existing claims when upgrading. The general schema does not itself grant account access or qualify a task for autonomous execution.
