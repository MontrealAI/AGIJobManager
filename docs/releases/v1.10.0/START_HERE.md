# Start here — AGIJobManager v1.10.0

1. Read `RELEASE_NOTES.md` and `VALIDATION.md` for implemented behavior, evidence and remaining limits.
2. Open `source/README.md` for the current system overview and `source/docs/START_HERE.md` for participant instructions.
3. For native Mac work, start with `source/docs/OPERATIONS/WORKFORCE_QUALIFICATION.md`, `CONFIDENTIAL_PROJECT_WORK.md`, and `COMPUTER_USE_CURRENT.md` in the same folder.
4. Private editions are Fleet 1.8.0, Agent 1.14.0 and Node 2.15.0. Their offline START_HERE.html, native setup and project guides explain separate compute/signing accounts, bounded pilot grants, encrypted private delivery, authority revocation, app pins, checkpoints and independent review. Open Launch-Native-Workforce.command in the compute account after setup. Existing wallet services retain their own launchers.
5. New work uses schema 6/7 operator-budget economics without review retainers. Preserve original operator state, earned claims, reservations and recovery policies when upgrading.
6. The manual `agijobmanager-usdc.html` console and `source/hardhat/README.md` require your verified deployment; this release deploys no contract and opens no intake.
7. Verify downloads against `SHA256SUMS.txt` and `RELEASE_MANIFEST.json`.

Actual Mac permissions, live models, signed-in accounts, restart behavior, independent real-job outcomes, costs and external assurance must be commissioned. Production native admission requires independently signed evidence for the exact source/runtime/specification. Included fixtures and an unexecuted commissioning matrix are not that evidence.
