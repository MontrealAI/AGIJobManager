## Native Alpha project transfer and recovery

The [Alpha project handoff](../../successor/ALPHA_PROJECT_HANDOFF.md) validates the pinned native public-data dossier, retains its original bytes, project/cycle identity and complete history, and requires explicit row/unit mapping and rights confirmation. Node and closed browser-worker adapters perform the same replay. Users run actual local work, then enter a separate six-decimal USDC price to export an unfunded draft; importing a project grants no authority, independent approval, payment or production admission.

The bilingual Builder adds explicit browser save/load/clear controls, fresh confirmation after reload, original-dossier and complete-history exports, and editable offline sources. A requested download does not prove that a durable file was saved; retain the original dossier and verify exports before closing. Browser storage may be unavailable, cleared or quota-limited. The pinned Alpha validator is retained unchanged with Apache-2.0 provenance and the nested Jobs compiler's MIT license. Compressed trusted editable-source inventory is byte-length/hash checked; unsupported decompression leaves project JSON exports available. These vendored sources do not change npm dependency resolutions.
