# Start here — AGIJobManager v1.18.0

To continue a native public-data Alpha project, use the [Builder](../../successor/README.md) and [Alpha transfer guide](../../successor/ALPHA_PROJECT_HANDOFF.md). Inspect the original dossier, confirm row/unit mapping and rights, run local work, then enter a separate USDC price for an unfunded draft. Save locally or verify exported files before closing; recovery requires fresh confirmation and grants no payment or production authority.

Use the [optional metadata-router guide](../../DEPLOYMENT/OPTIONAL_METADATA_ROUTER.md) only if that helper is needed. Review the original journal and exact-source verification requirements before any separately authorized deployment or recovery request. A verified router is still unconfigured. Source qualification does not establish a live address's explorer status or operational readiness.

For the manager itself, follow the [second-deployment checklist](../../DEPLOYMENT/SECOND_MAINNET_RELEASE.md), [scoped qualification decision](../../DEPLOYMENT/SECOND_MAINNET_QUALIFICATION_DECISION.md) and [Hardhat guide](../../../hardhat/README.md). Preserve the original instance, its jobs/claims and its original compiler/deployment records.

The COMPLETE ZIP includes source, contracts, deployment scripts, tests and operator guides. Standalone USDC and English/French SUCCESSOR Builder assets remain included. Local Builder work needs no wallet, account or provider key. The previous immutable v1.17.1 assets remain available unchanged.

See [validation](VALIDATION.md), [release notes](RELEASE_NOTES.md), [recovery](RECOVERY_GUIDE.md) and the [Pages inventory guide](../../ui/GITHUB_PAGES.md). This software candidate does not authorize public-chain transactions, owner configuration or paid intake.
