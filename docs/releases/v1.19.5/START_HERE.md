# AGIJobManager v1.19.5 — start here

This edition adds free inspection of complete native Alpha transformation campaigns through a developer API. The current Alpha pilot permits zero currency allowances: **positive paid proposals are unsupported**. Inspection grants no execution, signing, spending, review or settlement authority. Software publication does not open paid intake.

## Get a useful result first

For a browser-only first result, use the existing [SUCCESSOR Ω Builder](../../successor/README.md): create a public-data report or a simple website, inspect the files, try a measured improvement, download and restore the project. The Builder and its immutable v1.19.4 code pin are preserved. No account, wallet or provider key is needed for its two local engines. Custom mission execution remains unavailable until commissioned.

For campaign inspection, use one verified checkout and its matching qualification record. Keep the original public `transformational-intelligence/v1` campaign. Follow the [installed adapter API](../../successor/TRANSFORMATIONAL_WORK.md): supply the exact compatible native Alpha inspector and the consuming runtime’s independently obtained `expectedBindingsDigest`. Do not copy the expected digest from the imported file. Imported data cannot install its own validator.

Free inspection preserves the native campaign’s declared route. Creating a separate positive USDC proposal would require a charter and settlement route both explicitly set to USDC and an independently authorized nonzero USDC cap; the current native pilot does not supply that allowance. A zero USDC cap remains zero. Never edit a completed campaign to make an import pass. A refusal is a useful inspection result, not a reason to increase authority or invent an allowance.

The supported outcome is an inert inspected campaign or an explicit rejection. There is no new console button, automatic worker assignment, live execution, paid native proposal or transaction. See [release notes](RELEASE_NOTES.md), [validation](VALIDATION.md) and [recovery](RECOVERY_GUIDE.md).

## Existing operators

Keep each deployed Manager, journal, original source and jobs together. Ubuntu Hardhat initial creation retains local hidden ephemeral deployer-key entry; governance remains with the Ledger on Mac Studio. Never put a key in arguments, dotenv files, history or logs. This release requires no mainnet deployment, ENS action, token approval or unpause. Read [deployment identity and commands](../../RELEASE_GUIDE.md) only for a separately authorized operation.
