1. Read RELEASE_NOTES.md and VALIDATION.md for behavior, executed evidence and remaining limits.
2. Open source/README.md for the current system overview and source/docs/START_HERE.md for role instructions.
3. Read source/docs/OPERATIONS/OPERATING_QUALIFICATION.md before upgrading native production. Policy v2 needs fresh signatures; existing operator-budget participant policies are separate.

5. Private companions are Fleet 1.9.0, Agent 1.15.0 and Node 2.16.0. Open their offline START_HERE.html, preserve data directories and journals, and begin in observation. Keep signing and native compute in separate Standard Mac accounts.
6. New work uses operator budgets without retainers. Preserve prior claims, recovery policies, accumulated spending and reservations.
7. Verify downloads against SHA256SUMS.txt and RELEASE_MANIFEST.json. The standalone USDC console requires a separately verified deployment.

Physical Mac/provider commissioning, independent real-job outcomes, actual economics and external security review remain necessary. Native/private payment handoff and general automated moderation remain unimplemented. Test fixtures and synthetic scenarios cannot qualify production.
