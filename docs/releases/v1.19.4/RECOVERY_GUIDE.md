# v1.19.4 recovery

Keep complete JSON project history and a downloaded copy of its original edition. Browser storage is a convenience copy; retain your own file.

If an Alpha/Manager history belongs to an earlier edition, the current receiver offers **Download original** and the [immutable v1.19.3 release](https://github.com/MontrealAI/AGIJobManager/releases/tag/v1.19.3). Download its English or French offline Builder and inspect the unchanged history there. The current edition retains saved data and any open workspace. It does not treat mismatched history as inspected or import old permissions. Begin new work through a fresh Alpha cycle.

For an interrupted creator campaign, preserve its original checkout, source-bound catalog, public plan, session and receipts. Follow the [Ubuntu recovery procedure](../../deployment/ubuntu-ephemeral-creator.md) before entering a key or attempting anything further. An invalid key-entry line stays hidden until Enter or cancellation; start the reviewed route again after a rejected line. Never substitute a newer release into an existing campaign or repeat a creation merely to refresh documentation.

Governor configuration remains a separate Mac Studio Ledger operation. Live deployment, signing, funding, activation and authority changes need their own authorization. Existing deployments remain read-only within this release work.
