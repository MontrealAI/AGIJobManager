# AGIJobManager v1.19.4

This release candidate corrects hidden terminal input and public-mission validation, preserves earlier Builder history recovery, and adds a bilingual Computer Use receipt page with separately priced unsigned USDC proposals and complete same-project history.

Use public, licensed or synthetic non-personal inputs only. For Computer Use evidence, open the [English receipt page](https://montrealai.github.io/AGIJobManager/computer-receipt/) or [French receipt page](https://montrealai.github.io/AGIJobManager/fr/computer-receipt/). Select the Alpha handoff, Fleet native return and frozen Jobs report for the same project; include the complete Alpha workspace archive to retain earlier work, strategies and reviews. Confirm the public inputs, enter a new exact USDC amount, and inspect the unsigned proposal. Download complete Manager project history and retain a separate copy before closing or moving devices. Reopening revalidates the original records and restores no operating authority.

To return to Alpha on another device, use the page's two Alpha downloads: restore the original complete workspace first, then import the latest native history into that same project. The single Manager history file retains both for later recovery.

For the existing local Builder, begin with the [Builder guide](../../successor/README.md) and [Alpha continuity guide](../../successor/ALPHA_PROJECT_HANDOFF.md). The [computer receipt integration](../../../scripts/integrations/README.md) retains the supplied project, execution and review records without importing operating authority.

For a separately authorized fresh deployment, use the [Ubuntu hidden-prompt Hardhat guide](../../deployment/ubuntu-ephemeral-creator.md). Enter the deployer key locally and ephemerally; never place it in arguments, environment, files, history or logs. Governor operations remain on the Mac Studio Ledger. Existing deployments remain read-only within this work.

This preparation snapshot is not a qualification receipt. Publication requires all eight exact-final-source workflows, the complete candidate artifact and attestations. See [validation](VALIDATION.md), [release notes](RELEASE_NOTES.md) and [recovery](RECOVERY_GUIDE.md). No live deployment, signing, funding, activation or authority change is supplied by this software release.
