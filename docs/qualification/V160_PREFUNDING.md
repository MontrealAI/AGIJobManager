# v1.6.0 qualification scope

The one-million-offer experiment identified an avoidable funding-before-rejection path. This release adds schema 3 employer pre-funding primitives, canonical pre-posting economic observations, measured-value evidence references, capacity allocations and canonical cancellation receipt checks. Read [the integration guide](../OPERATIONS/PREFUNDING.md).

The local contract/tool regression passed 618 cases, including 18 new pre-funding/canonical-closure tests and the existing 32 admission cases. The compiler rebuilt all 60 Solidity sources without warnings or errors. The Solidity sources are unchanged from v1.5.0; deployment semantics, payouts, library links and permissions are preserved. Publication additionally requires exact-source CI, security, UI, documentation and pinned native-USDC fork qualification. The release's `VALIDATION.md` and `SOURCE_CI.json` identify the final source and results.

Public code is a reusable verification/observation API. The manual console does not enforce it. The private funding runner, wallet activation, allocation ledger and worker implementations are distributed separately and excluded from this repository. Passing local checks does not qualify M1/macOS operation, provider quality/costs, independent issuer/reviewer operation, employer value, sustained throughput or total human workload. The previous simulation remains historical experimental evidence; it was not rerun as a production test of v1.6.0.
