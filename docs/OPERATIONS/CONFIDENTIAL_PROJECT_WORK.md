# Confidential work and durable native projects

The separately delivered private companions support `computer-work/v3`, signed worker receipts, encrypted checkpoints, application installation pins, revocation and a durable Agent/Node project DAG. Use [private setup](PRIVATE_FLEET.md) and [workforce qualification](WORKFORCE_QUALIFICATION.md) before production.

The [V3 template](../../examples/computer-work-v3.json) contains placeholders, not a commissioned runtime. Validate the format with `npm run computer:check -- examples/computer-work-v3.json`. V2 remains supported.

V3 data classes are `public`, `confidential` and `restricted`. Private input references are opaque `agi-local://` or `agi-encrypted://` handles inside the encrypted packet. The runtime checks actual bytes against their hashes. Privacy policy binds exact recipients, retention, disclosure and model processing. Private plaintext cannot use the public publisher. Exported commitments and worker-signed receipts support selective disclosure; automatic private-chain posting/submission/voting is not implemented.

V3 permissions explicitly distinguish observation, broad whole-account desktop interaction and narrower broker-enforced scope. Low-level action allowlists and expiry are enforced. The native adapter rejects `broker-scoped` and `local-only` requests because a constrained credential/action broker and verified local-model path are not supplied. Whole-account UI control does not enforce per-site spending or business-action limits. Use dedicated trust domains and keep wallet/grant private keys in a separate account.

Native job wall-time limits can be configured up to seven days, with finite actions/calls, signed expiring authority, heartbeat leases and bounded resumes. A checkpoint binds encrypted state to the durable journal. Restart retains original calls, reservations and wall time, closes the original execution, and observes the current screen before proceeding. Uncertain or uncheckpointed desktop mutations block resumption. Revocation is checked before dispatch and at 250 ms intervals; in-flight effects cannot be undone.

The private project coordinator runs in the signing account. It validates a frozen acyclic plan, reserves all stages within the parent cost ceiling, signs each exact child, schedules ready stages and verifies worker receipts. Downstream input bindings require an independent review of the source bytes. It assembles a final independently reviewed artifact, and routes rejection evidence to repair work orders. A crash can re-export the same grant but cannot create a fresh one. The current coordinator supports one configured Agent/Node pair; remote ciphertext transport must be provisioned separately. Automatic repair/reassignment with new authority and atomic parent/child settlement are not implemented.

These are software paths tested using protocol/model/desktop fixtures. No physical Mac, signed-in live account, sustained long job, customer outcome, actual settlement, provider invoice or qualified external review was produced by the release tests. The broad commissioning matrix in the private bundle is explicitly unexecuted. A model announcement motivates evaluation; it does not prove fleet readiness.
