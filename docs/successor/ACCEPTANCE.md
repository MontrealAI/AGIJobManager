## Reproduce local evidence

```bash
npm ci
npm --prefix hardhat ci
npm --prefix ui ci
npm run successor:test
node scripts/site/build.mjs
node scripts/site/check.mjs
node --test scripts/site/employer-model.test.mjs scripts/successor/preservation.test.mjs
npx playwright install --with-deps chromium
node scripts/site/browser-test.mjs
node scripts/site/employer-browser-test.mjs
npm run successor:browser
npm run successor:rehearse
npm run docs:check
python3 scripts/release/test-release-gates.py
python3 scripts/release/test-dependency-boundaries.py
```

All CI-mandated contract, invariant/fuzz, fork, security, UI and release checks remain required in addition. The browser suite uses the existing UI axe dependency; both root and UI lockfiles must be installed. The axe scan covers the Builder interface and excludes the intentionally script-disabled preview iframe; separate byte/structure checks and actual navigation checks cover generated artifacts. Tests generate JSON evidence with browser version and explicit unperformed human sessions. There is no screenshot of a fictitious provider run.

Initial local environment: Linux, Node 24.19.0; existing locked root Playwright 1.58.1. The standard browser download failed in this environment. A scratch-only Chromium 153.0.8010.0 was used through `SUCCESSOR_CHROMIUM`; no repository dependency or production runtime was changed. CI must independently rerun on Node 22.23.2 and its locked Playwright browser. A local pass on a different browser is not a substitute for exact-source CI.

## Finite external gates

The v1.16.1 recovery regressions add held real-worker responses in both languages. They verify that pending execution disables conflicting actions, Stop preserves the complete chosen state despite a late response, rejected replacement imports revoke old restore consent, rollback requires a previously chosen version, and larger-text state survives language changes. Published-package checks now cover the exact nine-file inventory, qualification/asset/source bindings and bounded archive extraction.
