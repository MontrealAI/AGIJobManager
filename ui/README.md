# AGIJobManager UI Directory

This directory contains two UI tracks:

1. **Broader/full UI in development** (Next.js app, tests, deterministic build pipeline).
2. **Versioned standalone HTML artifacts** (single-file browser interfaces, including the genesis mainnet page).

## Start here

- Standalone HTML artifact guide: [`../docs/ui/STANDALONE_GENESIS_JOB_MAINNET_HTML_UI.md`](../docs/ui/STANDALONE_GENESIS_JOB_MAINNET_HTML_UI.md)

## Quick start for the full UI track

```bash
cd ui
npm ci
npm run dev
```

## Required quality checks (existing repo commands)

```bash
cd ui
npm run check:no-binaries
npm run lint
npm run typecheck
npm run test
npm run test:e2e
npm run test:a11y
npm run test:security
npm run docs:versions
npm run docs:contract
npm run docs:check

npm run verify:ipfs
npm run verify:deterministic
npm run verify:committed-html
```
